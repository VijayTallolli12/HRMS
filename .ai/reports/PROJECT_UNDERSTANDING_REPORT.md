**Project Understanding Report**

**Product Summary**
- Enterprise-grade HRMS for multi-company, multi-branch organizations. Core capabilities: employee lifecycle (onboarding, profiles), attendance, leave management, expenses, payroll, role-based access, reporting, notifications, and mobile API support.

**Architecture Overview**
- Backend: Laravel 12 on PHP 8.4.
- Frontend: Livewire 3 + Tailwind CSS for admin UI; mobile clients use versioned REST API protected by Sanctum.
- AuthZ: Spatie Permission for RBAC.
- Persistence: MySQL 8 (utf8mb4). Preferred tenancy: database-per-tenant for enterprise deployments; optional single-db (tenant_id) for early-stage customers.
- Async/Workers: Queue workers for payroll jobs, notifications, and heavy reports.

**Functional Modules**
- Auth & User Management (SSO/Sanctum, 2FA optional)
- Organization (Tenants, Companies, Branches)
- Employees (profiles, employment history)
- Attendance (punch-in/out, shifts, integrations)
- Leave Management (policies, approvals)
- Expense Management (claims, approvals)
- Payroll (runs, payslips, tax rules)
- Reports & Analytics (exportable, scheduled)
- Notifications (email/SMS/push, templates)
- Settings & Audit Logs
- Mobile API (versioned)

**Database Strategy**
- Core entities: tenants, companies, branches, users, employees, roles, permissions, attendance, leaves, expenses, payroll_runs, audit_logs, notifications, settings.
- Tenancy model: database-per-tenant by default for isolation and compliance; support a single-db mode behind feature flag `TENANCY_MODE` for cost-effective deployments.
- Migrations: central migration repository plus tenant provisioning scripts to run migrations per-tenant DB.

**Folder Structure (recommended)**
- `app/` domain models and services
- `app/Http/Controllers` API and web controllers
- `app/Services` business logic kept testable and framework-agnostic
- `database/migrations` shared migrations; `database/seeders` for base data
- `resources/views` Livewire components and blade views
- `routes/api.php`, `routes/web.php` (versioned API)
- `tests/` unit and feature tests
